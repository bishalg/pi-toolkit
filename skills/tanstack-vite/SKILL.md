# TanStack Router & Vite SPA Engineering Skill

This skill guides Pi on architectural best practices, routing patterns, loader-based data fetching, and SEO contracts for **Vite Single Page Applications (SPAs)** powered by **TanStack Router** and **TanStack Query**.

---

## 1. Core Architecture & Route Tree

1. **Root Route Setup (`routes/__root.tsx`)**:
   - The root route defines the application layout shell, providers, and global `<HeadContent />`:

   ```tsx
   import { createRootRouteWithContext, HeadContent, Outlet } from "@tanstack/react-router";
   import type { QueryClient } from "@tanstack/react-query";

   export interface RouterContext {
     queryClient: QueryClient;
   }

   export const Route = createRootRouteWithContext<RouterContext>()({
     head: () => ({
       meta: [
         { charSet: "utf-8" },
         { name: "viewport", content: "width=device-width, initial-scale=1" },
         { title: "Platform | My Organization" },
       ],
     }),
     component: RootLayout,
   });

   function RootLayout() {
     return (
       <div className="min-h-screen bg-background text-foreground">
         <HeadContent />
         <Outlet />
       </div>
     );
   }
   ```

2. **File-Based Routing Conventions**:
   - `routes/__root.tsx`: Top-level router shell.
   - `routes/index.tsx`: Homepage `/`.
   - `routes/$locale.tsx`: Dynamic parameter layout (e.g. `/en`, `/hi`).
   - `routes/$locale/$category/$slug.tsx`: Nested dynamic leaf route.

3. **Type-Safe Search Parameters**:
   - Validate search parameters with schemas using `validateSearch`:
   ```tsx
   export const Route = createFileRoute("/dashboard")({
     validateSearch: (search: Record<string, unknown>) => ({
       page: Number(search.page || 1),
       filter: (search.filter as string) || "all",
     }),
   });
   ```

## 2. Mandatory `head()` SEO Metadata Contract

> ⚠️ **CRITICAL MIGRATION TRAP**: In Vite SPAs, Next.js metadata constructs (`export const metadata` and `generateMetadata()`) are **completely ignored** as dead code. Every route must explicitly define a `head()` export.

### Route Metadata Pattern

```tsx
export const Route = createFileRoute("/$locale/items/$id")({
  loader: async ({ context: { queryClient }, params }) => {
    return queryClient.ensureQueryData(itemQueryOptions(params.id));
  },
  head: ({ params, loaderData }) => ({
    meta: [
      { title: `${loaderData.title} | My Organization` },
      { name: "description", content: loaderData.summary },
      { property: "og:title", content: loaderData.title },
      { property: "og:description", content: loaderData.summary },
      { property: "og:image", content: loaderData.imageUrl },
      { property: "og:type", content: "article" },
      { name: "twitter:card", content: "summary_large_image" },
    ],
    links: [{ rel: "canonical", href: `https://my-org.com/${params.locale}/items/${params.id}` }],
  }),
  component: ItemDetailView,
});
```

## 3. The SPA Navigation Contract

1. **Never Imperatively Mutate React-Owned `<head>` Nodes**:
   - Do NOT run manual DOM scripts that `document.head.removeChild(node)` on tags generated by React or TanStack Router (e.g. hreflang tags, meta tags).
   - Imperative removal causes React’s commit phase to crash with `NotFoundError: The node to be removed is not a child of this node`, leaving the router permanently stuck in a `pending` state.
2. **E2E Click-Navigation Verification**:
   - `page.goto()` bypasses client-side routing and triggers a full HTML reload.
   - E2E tests for SPAs must test navigation using real user link clicks:
   ```typescript
   await page.click('a[href="/en/items/123"]');
   await expect(page.getByTestId("spa-route-mounted")).toBeVisible();
   ```

## 4. Data Fetching: Loaders vs `useEffect`

1. **Zero Fetch Loops in `useEffect`**:
   - Strictly avoid triggering initial data queries inside `useEffect(() => { fetch(...) }, [])`.
   - Use TanStack Route `loader` combined with TanStack Query `queryClient.ensureQueryData()`.
2. **Cache Management**:
   - Keep query keys standardized as tuples: `['items', id]` or `['user', 'profile']`.
   - Loaders initiate fetch before the view component mounts, eliminating jarring layout shifts and blank flash states.

## 5. Vite Configuration & Production Builds

1. **Proxy Routes & API Forwarding**:
   - In Vite development, define API proxies in `vite.config.ts` or `src/proxy.ts`:
   ```typescript
   export default defineConfig({
     server: {
       proxy: {
         "/api": {
           target: "http://localhost:3001",
           changeOrigin: true,
         },
       },
     },
   });
   ```
2. **Manual Chunk Splitting**:
   - Separate heavy dependencies (React, TanStack Router, charting libraries) in `rollupOptions.output.manualChunks` to prevent massive monolithic JS bundles.
3. **SPA Rewrites**:
   - For static hosting (Vercel, Cloudflare, S3), configure single-entry SPA rewrites to `index.html`:
   ```json
   {
     "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
   }
   ```
